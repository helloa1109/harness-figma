**[Major] 이슈 #1 — 카드 너비 하드코딩**
- 위치: `src/components/ui/TripCard.css:5`
- 현재: `width: 20rem;`
- 문제: 반응형 레이아웃에서 컨테이너에 맞춰 늘어나지 못함. Gallery 스토리에서도 `20rem` 고정.
- 제안:
  ```css
  .trip-card {
    width: 100%;
    max-width: 20rem;
  }
  ```

**[Minor] 이슈 #2 — 커버 이미지 높이 하드코딩**
- 위치: `src/components/ui/TripCard.css:15`
- 현재: `height: 11.25rem;`
- 제안: `aspect-ratio: 5 / 3;` 로 비율 기반 정의(반응형 대응 + 디자인 토큰 의존도 감소)

| 항목 | 상태 | 비고 |
|---|---|---|
| 시맨틱 마크업 | ✅ Pass | `<article>`, `<h3>` 사용 |

| 컬러 대비 | ✅ Pass | `--color-neutral-500` on `--color-neutral-0` ≈ 4.6:1 (WCAG AA 통과) |

**[Major] 이슈 #3 — 이미지 alt 의미 부재**
- 위치: `src/components/ui/TripCard.tsx:32`
- 현재: `<img src={image} alt="" ... />`
- 문제: 여행지를 시각적으로 인식해야 하는 사용자에게 정보 손실. 장식 이미지로 단정할 수 없음.
- 제안:
  ```tsx
  <img src={image} alt={`${title} 사진`} className="trip-card__cover-img" />
  ```

**[Minor] 이슈 #4 — 인터랙션 의도 모호**
- 위치: `src/components/ui/TripCard.tsx:26-30`
- 문제: 카드가 클릭 가능해 보이지만 `onClick`, `:hover`, `:focus-visible` 스타일이 없음
- 제안: 클릭 가능하다면 `<a>` 또는 `role="button"` + `tabIndex={0}` + `:focus-visible { outline: 2px solid var(--color-brand-500); }` 추가
